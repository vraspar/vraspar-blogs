A quick update on what I've been doing since leaving Microsoft earlier this year.

I loved my time on the ONNX Runtime team and the people I worked with, but I wanted to try building something of my own. It felt like the right time to give it a shot.

My cofounder Ali Abdoli and I started with a different idea and pivoted along the way. We're now building [Tenjin](https://tenjin.sh/).

## The problem

Agents keep getting better, but giving them useful tools still feels really messy. You need to find the tools, set up accounts and API keys, install integrations, and keep reminding your agent to use them.

## What we're building

We're trying to make this super easy. Tenjin looks at what your agent is working on and suggests a tool when it could help. You don't have to know it exists or ask for it by name.

We want one vertically integrated experience for discovering tools, using them, and paying for them. You install once, have one place to add funds, and set your spending limits.

Whether you're building software, making a video, or doing research, we want to help your agent use the best tools for the job, with quality, speed, and cost in mind.

## Where it's at

We have an early alpha for Claude Code with a small set of tools. It's a first step toward that vision, and we're iterating fast. We plan to add more tools and support other agents too.

I'd love for you to try it and tell us what you wish your agent could do: [github.com/BackTrackCo/tenjin-agent](https://github.com/BackTrackCo/tenjin-agent).

I'm enjoying the adventure so far. I'll keep writing here about what we're building and learning as we go.
